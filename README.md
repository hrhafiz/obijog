# অভিযোগ লিখুন — Vercel-এ ডিপ্লয় করার নির্দেশিকা

## এই প্রজেক্টে কী কী ফাইল আছে
```
vercel-setup/
├── public/
│   └── index.html     → মূল অ্যাপ (ফর্ম + প্রিভিউ + PDF/DOC/Print + অনলাইনে সংরক্ষণ)
├── api/
│   ├── save.js         → PDF/DOC আপলোড করে Vercel Blob storage-এ রাখে, লিংক ফেরত দেয়
│   └── list.js          → আগে সংরক্ষিত সব ফাইলের তালিকা ফেরত দেয়
├── package.json         → @vercel/blob ডিপেন্ডেন্সি + "type":"module"
└── .gitignore
```
"অনলাইনে সংরক্ষণ করুন" বাটনে চাপলে PDF ও DOC — দুটো ফাইলই সরাসরি সার্ভারে (Vercel Blob)
জমা হয় এবং লিংক পাওয়া যায়। "সংরক্ষিত" ট্যাবে গেলে আগের সব ফাইল দেখা ও ডাউনলোড করা যায়।

---

## পদ্ধতি ১ (সবচেয়ে সরাসরি): Vercel CLI দিয়ে — GitHub লাগবে না

### ধাপ ১ — প্রয়োজনীয় জিনিস
- কম্পিউটারে **Node.js** ইনস্টল থাকতে হবে (nodejs.org থেকে LTS ভার্সন নামিয়ে নিন)।
- একটা টার্মিনাল/কমান্ড প্রম্পট।

### ধাপ ২ — Vercel CLI ইনস্টল করুন
টার্মিনালে লিখুন:
```
npm install -g vercel
```

### ধাপ ৩ — এই ফোল্ডারে যান
আমার দেওয়া `vercel-setup` ফোল্ডারটি ডাউনলোড/এক্সট্র্যাক্ট করে সেখানে টার্মিনাল দিয়ে ঢুকুন:
```
cd path/to/vercel-setup
```

### ধাপ ৪ — লগইন করুন
```
vercel login
```
এটি আপনার ব্রাউজার খুলে দেবে — সেখানে ইমেইল দিয়ে Vercel অ্যাকাউন্টে (না থাকলে ফ্রি
অ্যাকাউন্ট তৈরি করে) লগইন করুন।

### ধাপ ৫ — ডিপ্লয় করুন
```
vercel
```
কয়েকটি প্রশ্ন আসবে — সবগুলোতে এন্টার চেপে ডিফল্ট মান রাখতে পারেন:
- "Set up and deploy?" → Enter (Yes)
- "Which scope?" → আপনার অ্যাকাউন্ট বেছে নিন
- "Link to existing project?" → N (নতুন প্রজেক্ট)
- "Project name?" → Enter (ডিফল্ট নাম রাখুন বা নিজের মতো লিখুন)
- "In which directory is your code located?" → Enter (./ — বর্তমান ফোল্ডার)
- Framework detect করতে বললে → "Other" বেছে নিন

শেষে একটা প্রিভিউ লিংক (যেমন `https://vercel-setup-xxxx.vercel.app`) দেখাবে — এটাই
আপনার টেস্ট সাইট।

### ধাপ ৬ — প্রোডাকশনে পাঠান (স্থায়ী লিংক)
```
vercel --prod
```
এবার একটা স্থায়ী লিংক পাবেন (যেমন `https://vercel-setup.vercel.app`) — এটাই আপনার
চূড়ান্ত ওয়েবসাইট ঠিকানা।

---

## পদ্ধতি ২: GitHub দিয়ে (ড্যাশবোর্ড থেকে)
1. GitHub-এ একটা নতুন রিপোজিটরি বানিয়ে এই ফোল্ডারের সব ফাইল push করুন।
2. https://vercel.com → লগইন → "Add New… → Project" → রিপোটি import করুন।
3. Framework Preset: **Other** নির্বাচন করুন। Build Command/Output Directory খালি
   রাখলেই চলবে।
4. "Deploy" চাপুন।

---

## ধাপ ৭ (দুই পদ্ধতির জন্যই আবশ্যক) — Vercel Blob storage চালু করুন
এটা ছাড়া "অনলাইনে সংরক্ষণ করুন" বাটন কাজ করবে না।

1. আপনার Vercel প্রজেক্ট ড্যাশবোর্ডে যান (vercel.com → প্রজেক্টে ক্লিক করুন)।
2. উপরের "Storage" ট্যাবে যান।
3. "Create Database" → **Blob** বেছে নিন → একটা নাম দিয়ে "Create" চাপুন।
4. এটি তৈরি হলে `BLOB_READ_WRITE_TOKEN` নামে একটা এনভায়রনমেন্ট ভ্যারিয়েবল
   স্বয়ংক্রিয়ভাবে প্রজেক্টে যোগ হয়ে যাবে — আলাদা করে কিছু কপি-পেস্ট করতে হবে না।
5. এটি কার্যকর করতে একবার রিডিপ্লয় করুন:
   - CLI দিয়ে করলে: আবার `vercel --prod` চালান।
   - ড্যাশবোর্ড থেকে করলে: "Deployments" ট্যাব → সর্বশেষ ডিপ্লয়মেন্টের পাশে
     তিন-ডট মেনু → "Redeploy"।

---

## ধাপ ৮ — পরীক্ষা করুন
1. আপনার Vercel URL-এ যান।
2. একটা আবেদন পূরণ করুন।
3. "অনলাইনে সংরক্ষণ করুন" চাপুন — PDF ও DOC দুটোর লিংক দেখানো উচিত।
4. "সংরক্ষিত" ট্যাবে গিয়ে দুটো ফাইলই তালিকায় দেখা ও ডাউনলোড করা যাচ্ছে কিনা যাচাই করুন।

---

## সমস্যা হলে
- **"অনলাইনে সংরক্ষণ করতে সমস্যা হয়েছে" এরর** → সাধারণত Blob storage এখনো চালু করা হয়নি,
  বা চালু করার পর রিডিপ্লয় করা হয়নি (ধাপ ৭ আবার দেখুন)।
- **"সংরক্ষিত" ট্যাবে কিছু দেখাচ্ছে না** → এখনো কিছু সংরক্ষণ করা হয়নি, অথবা `/api/list`
  ফাংশনটি ঠিকমতো ডিপ্লয় হয়নি — Vercel ড্যাশবোর্ডে "Deployments" → সর্বশেষ ডিপ্লয়মেন্ট
  খুলে "Functions" লগ চেক করুন।
- **আপলোড খুব বড় ফাইলে ব্যর্থ হচ্ছে** → Vercel-এর ফ্রি (Hobby) প্ল্যানে প্রতিটি
  ফাংশন-রিকোয়েস্টের একটা সর্বোচ্চ সাইজ সীমা আছে (~৪.৫MB); এই অ্যাপের PDF/DOC সাধারণত
  অনেক ছোট হওয়ায় সমস্যা হওয়ার কথা না।

## গুরুত্বপূর্ণ নোট
- "সংরক্ষিত" তালিকা এই মুহূর্তে **সবার জন্য একই** (কোনো লগইন/ব্যবহারকারী-আলাদাকরণ নেই)।
  একার ব্যবহারের জন্য এটা ঠিক আছে। একাধিক মানুষ ব্যবহার করলে বা প্রাইভেসি দরকার হলে
  জানাবেন — সহজ পাসওয়ার্ড-সুরক্ষা বা প্রতি-ব্যবহারকারী আলাদা ফোল্ডার যোগ করে দিতে পারি।
- Vercel Blob storage-এর ফ্রি কোটা এই ধরনের ব্যক্তিগত/ছোট ব্যবহারের জন্য যথেষ্ট।
